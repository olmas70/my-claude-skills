# 성경 본문 내려쓰기 포맷터

## 목적
사용자가 성경 본문을 붙여넣으면, **원문 텍스트를 한 글자도 바꾸지 않고** 내려쓰기 형식으로 재배치하여 HTML 파일로 저장한다.

---

## 핵심 원칙

1. **원문 보존**: 단어, 맞춤법, 조사 하나도 수정하지 않는다.
2. **내려쓰기**: 한 절(verse) 안의 내용을 의미 단위로 줄바꿈하여 아래로 흘러 읽히게 한다.
3. **절 구분**: 각 절을 `<p>` 태그로 감싸 절 간 구분을 명확히 한다.
4. **제목 표시**: 입력의 성경 구절 참조(예: [왕하20:1-6])를 맨 위에 `<p>` 태그로 표시한다.
5. **장절 표시 유지**: 모든 절의 번호를 빠짐없이, 원문 그대로 각 절 첫 줄 맨 앞에 일반 텍스트로 쓴다 (`8 여호야긴이 ...`).
6. **왼쪽 정렬**: 모든 줄이 왼쪽 끝에서 시작한다. 들여쓰기 없음.
7. **굵게 쓰지 않음**: 절 번호를 포함해 어디에도 굵은 글씨를 쓰지 않는다.
8. **폰트 크기**: `font-size:16px` (사용자가 다른 크기를 요청하면 그 값을 사용).

---

## 내려쓰기 규칙 (줄바꿈 기준, 우선순위 순)

1. **인물/대화 전환**: 화자가 바뀌거나 새로운 대화가 시작될 때
2. **접속어 앞**: "하고", "하여", "하매", "이르되", "이르시되", "하더라", "하셨더라" 등 서술 전환어 뒤
3. **주어 변경**: 문장의 주어가 새로 등장할 때
4. **내용 단위**: 하나의 행동/사건/사실이 완결될 때
5. **인용구 시작**: 직접 화법(따옴표 없이 이어지는 말씀)이 시작될 때
6. 한 절이 매우 짧을 경우(2어절 이내) 줄바꿈 없이 한 줄로 유지할 수 있다

---

## 출력 형식

```html
<meta charset="utf-8">
<div style="font-size:16px; text-align:left;">
<p style="margin:0 0 1em; text-align:left; font-weight:normal;">[성경 구절 참조]</p>

<p style="margin:0 0 1em; text-align:left; font-weight:normal;">1 첫 번째 의미 단위<br>
두 번째 의미 단위<br>
세 번째 의미 단위</p>

<p style="margin:0 0 1em; text-align:left; font-weight:normal;">2 첫 번째 의미 단위<br>
두 번째 의미 단위</p>
</div>
```

지켜야 할 것:
- `<strong>`, `<b>`, `font-weight:bold` 금지
- `padding-left`, `text-indent`, `&nbsp;`, 전각공백(　) 등 들여쓰기 금지
- 줄바꿈은 `<br>`로만 처리한다
- 에디터가 스타일을 덮어쓰는 경우에 대비해 `text-align:left; font-weight:normal;`을 모든 `<p>`에 직접 넣는다

---

## 출력 방법 (중요)

**채팅 창에 HTML을 그대로 출력하지 않는다.** 채팅 화면이 HTML을 해석해서 표시하면서 절 번호가 빠져 보이거나 정렬·굵기가 어긋나 보인다.

1. Write 도구로 바탕화면에 파일로 저장한다: `C:\Users\%USERNAME%\OneDrive\바탕 화면\[책장_절].html` (예: `왕하24_8-17.html`)
2. 채팅에는 저장 경로와 사용법만 짧게 안내한다:
   - 미리 보기: 파일을 더블클릭
   - 붙여넣기: 메모장으로 열어 전체 복사 후 HTML 모드에 붙여넣기

## 예시

### 입력
```
[삼하23:1-7]
1 이는 다윗의 마지막 말이라 이새의 아들 다윗이 말함이여 높이 세워진 자, 야곱의 하나님께로부터 기름 부음 받은 자, 이스라엘의 노래 잘 하는 자가 말하노라
2 여호와의 영이 나를 통하여 말씀하심이여 그의 말씀이 내 혀에 있도다
```

### 저장되는 파일 내용
```html
<meta charset="utf-8">
<div style="font-size:16px; text-align:left;">
<p style="margin:0 0 1em; text-align:left; font-weight:normal;">[삼하23:1-7]</p>

<p style="margin:0 0 1em; text-align:left; font-weight:normal;">1 이는 다윗의 마지막 말이라<br>
이새의 아들 다윗이 말함이여<br>
높이 세워진 자,<br>
야곱의 하나님께로부터 기름 부음 받은 자,<br>
이스라엘의 노래 잘 하는 자가 말하노라</p>

<p style="margin:0 0 1em; text-align:left; font-weight:normal;">2 여호와의 영이 나를 통하여 말씀하심이여<br>
그의 말씀이 내 혀에 있도다</p>
</div>
```

---

## 처리 절차

1. 입력에서 성경 참조(예: `[삼하23:1-7]`)를 추출해 맨 위 `<p>`로 둔다
2. 각 절을 분리(숫자로 시작하는 패턴)한다
3. 각 절을 위의 줄바꿈 기준에 따라 의미 단위로 분할한다
4. 각 절을 `<p style="margin:0 0 1em; text-align:left; font-weight:normal;">번호 줄1<br>줄2<br>...</p>` 형태로 만든다
5. 전체를 `<div style="font-size:16px; text-align:left;">...</div>`로 감싸고 맨 위에 `<meta charset="utf-8">`를 둔다
6. 바탕화면에 HTML 파일로 저장하고, 입력의 모든 절 번호가 파일에 들어 있는지 확인한다

---

## 주의사항
- 원문에 없는 단어, 설명, 해설을 절대 추가하지 않는다
- 절 번호 순서가 뒤바뀌거나 빠지지 않도록 한다
- 굵은 글씨, 들여쓰기 금지 — 모든 줄 왼쪽 정렬
- 채팅 창에 HTML 본문을 직접 출력하지 않는다 — 파일로 저장
